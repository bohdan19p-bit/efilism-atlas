# Исследовательский атлас эфилизма (Atlas Efilismi · v3.7)

Автономный статический справочник и интерактивный граф понятий, принципов, аргументов, возражений и редакционных проверок для проекта **Efilism RUS**.

## Точки входа

- **`index.html`** — главная страница для GitHub Pages с быстрым выбором разделов и адаптацией под смартфоны.
- **`Corpus_Definitivum.html`** *(849 КБ)* — рекомендуемый стартовый справочник (быстро открывается на телефоне): 137 понятий, 9 принципов, 18 аргументов (108 тезисов), 12 сильных возражений, 139 библиографических URL (198 упоминаний) и 24 редакторских предложения.
- **`Atlas_Efilismi.html`** *(4,25 МБ)* — полный исследовательский граф и навигатор по всем модулям (рекомендуется открывать на ПК).
- **`Corpus_Kit/`** — набор из 6 Markdown-файлов и инструкции `00_Instructions.md` для подключения в качестве базы знаний к ИИ-помощнику (Gemini Gem, NotebookLM и др.).
- **`modules_v0_7/`** — сохранённый исторический снимок ранних модулей и архивных абзацев (`modules_v0_7/corpus.json`), на который ссылаются идентификаторы справочника.
- **`CHANGELOG_v3_7.md`** — полная исходная история версий v1.0–v3.7.

## Происхождение, редакция и статусы

- **Базовая редакция книги:** сопоставления и номера страниц в v3.7 привязаны к редакции монографии `ru(4)` от 23.11.2026 (529 PDF-страниц, 7 частей, 49 глав). При работе с более поздней редакцией (`ru(5)`, 536 PDF-страниц) сверяйте адреса по номеру параграфа (`§`) и текстовому якорю.
- **Статус аргументов в справочнике:** 7 условных аргументов, 8 с открытым нормативным основанием, 2 с открытой эмпирической посылкой, 1 открытый синтез.
- **Редакторские предложения (`REV-01`–`REV-24`):** рабочие предложения для рассмотрения автором, не утверждённый текст книги.
- **Воспроизводимые скрипты (`reproduce_*.py`):** 13 из 14 Python-скриптов выполняются автономно на распакованном архиве (проверка моделей без внешних зависимостей). Скрипт `reproduce_logica.py` сохранён как исторический сборщик v1.3–v1.4 и требует исходных путей `/mnt/data/Atlas_Efilismi_v1_3`.
- **Этическая граница:** обсуждение добровольного несоздания не допускает вреда, принуждения или вмешательства в автономию уже существующих субъектов.

## Публикация на GitHub Pages

1. Создайте отдельный публичный репозиторий (например, `efilism-atlas`) и загрузите всё содержимое этой папки в корень ветки `main` (включая скрытый файл `.nojekyll` — он отключает обработку Jekyll и ускоряет публикацию).
2. Откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Не переименовывайте HTML-файлы, папки `Corpus_Kit/` и `modules_v0_7/` и не меняйте регистр символов в именах — все локальные ссылки между модулями относительные и чувствительны к регистру.
4. После публикации проверьте:
   - открытие главной страницы `index.html` на компьютере и на смартфоне (ширина 390 px);
   - переходы `index.html` → `Corpus_Definitivum.html` → `Atlas_Efilismi.html` → обратно;
   - поиск по термину и ID (`ARG-08`, `CRI:O09`), раскрытие карточки возражения и ссылку на исторический фрагмент.
