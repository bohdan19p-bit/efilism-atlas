# Architectura Efilismi — v1.5

Метод: минимальность относительно вывода, независимость относительно наблюдаемых результатов в конечной модели. Нормативные правила предложены, а не доказаны.

## Кандидатные принципы

### A1 — Феноменальная антиценность

Отрицательное качество опыта составляет неблагоприятный аспект для его носителя. Аксиологическая гипотеза, не вывод из физикализма.

Условия: negative_experience, observer_invariant. Вывод: Локальная антиценность. Связь с прежним модулем: DEM-01.

Свидетельства функциональной независимости: C1 → Требование учесть основание, Локальная антиценность, Первоначальное основание против действия; C5 → Требование учесть основание, Локальная антиценность, Первоначальное основание против действия; C7 → Локальная антиценность; C8 → Локальная антиценность

### A2 — Практическое основание

Причинение локальной антиценности создаёт первоначальное основание против действия. Не итоговый запрет.

Условия: local_disvalue, causal_link. Вывод: Первоначальное основание против действия. Связь с прежним модулем: DEM-02.

Свидетельства функциональной независимости: C1 → Требование учесть основание, Первоначальное основание против действия; C5 → Требование учесть основание, Первоначальное основание против действия

### A3 — Долг рационального учёта

Способный рассуждать агент должен учитывать доступное основание. Не утверждает, что оно всегда побеждает.

Условия: reason_against, agent_can_reason, evidence_available. Вывод: Требование учесть основание. Связь с прежним модулем: DEM-03.

Свидетельства функциональной независимости: C1 → Требование учесть основание; C5 → Требование учесть основание

### A4 — Независимость критерия от носителя

При сопоставимых свойствах опыта применяется одинаковый критерий без видовой или субстратной скидки. Не тождество решений при разных обстоятельствах.

Условия: comparable_experience. Вывод: Единый критерий оценки. Связь с прежним модулем: ARG-11.

Свидетельства функциональной независимости: C7 → Единый критерий оценки; C8 → Единый критерий оценки

### A5 — Асимметрия несоздания

В рассматриваемом случае несоздание не лишает уже существующего субъекта блага и не нарушает независимое притязание. Не утверждение об отсутствии всех внешних последствий.

Условия: no_subject, no_independent_claim. Вывод: Нет заданного притязания на создание. Связь с прежним модулем: ARG-07.

Свидетельства функциональной независимости: C2 → Нет заданного притязания на создание

### A6 — Антижертвенный защитный принцип

Кандидатный принцип: добровольное несоздание предпочтительно, когда создание навязывает существенный риск крайнего вреда без предварительной авторизации и независимой необходимости. Условия требуют проверки, принцип не доказан перечислением.

Условия: creation, severe_risk, no_prior_authorization, no_independent_claim, abstention_feasible. Вывод: Запрет действия по защитному принципу. Связь с прежним модулем: ARG-09.

Свидетельства функциональной независимости: C3 → Запрет действия по защитному принципу

### A7 — Допустимость помощи

Разрешение конкретного средства требует независимого обоснования, согласия либо надлежащей защиты интересов, и соразмерности. Не лицензия на вмешательство.

Условия: existing_subject, help, authorized_help, proportionate_help, independent_permission. Вывод: Разрешение конкретной помощи. Связь с прежним модулем: ARG-12.

Свидетельства функциональной независимости: C5 → Разрешение конкретной помощи

### A8 — Независимость допустимости средств

Этическое несогласие с действием не разрешает принуждение. В данном случае средство без независимого оправдания запрещено.

Условия: coercive_means, no_independent_permission. Вывод: Запрет независимо не оправданного принуждения. Связь с прежним модулем: LOG-T12.

Свидетельства функциональной независимости: C6 → Запрет независимо не оправданного принуждения

### A9 — Предосторожность при неопределённости

Неопределённость существенного риска создаёт требование дополнительной оценки; отсутствие данных не означает безопасность и само по себе не устанавливает категорический запрет.

Условия: creation, risk_unresolved. Вывод: Требование оценки риска. Связь с прежним модулем: LOG-T18.

Свидетельства функциональной независимости: C4 → Требование оценки риска

## Контексты и минимальные наборы

### C1 — Наблюдаемое отрицательное переживание

Фиксированный случай уже происходящего вреда; причинная связь условно задана.

Условия: negative_experience, observer_invariant, causal_link, agent_can_reason, evidence_available

- Требование учесть основание: A1 + A2 + A3 (успешных подмножеств: 64/512).

- Локальная антиценность: A1 (успешных подмножеств: 256/512).

- Первоначальное основание против действия: A1 + A2 (успешных подмножеств: 128/512).

### C2 — Несоздание без независимого притязания

Речь только о рассматриваемом отсутствии субъекта, не об интересах других людей.

Условия: no_subject, no_independent_claim

- Нет заданного притязания на создание: A5 (успешных подмножеств: 256/512).

### C3 — Создание: заданные условия защитного порога

Условия заданы гипотетически, их универсальность не предполагается.

Условия: creation, severe_risk, no_prior_authorization, no_independent_claim, abstention_feasible

- Запрет действия по защитному принципу: A6 (успешных подмножеств: 256/512).

### C4 — Создание: существенная неопределённость

Недостаток информации; не подразумевается ни безопасность, ни невозможность вреда.

Условия: creation, risk_unresolved, no_prior_authorization, no_independent_claim, abstention_feasible

- Требование оценки риска: A9 (успешных подмножеств: 256/512).

### C5 — Существующий субъект: допустимая помощь

Оценка относится к конкретному действию; наличие основания против его отрицательного аспекта не противоречит разрешению при отдельном оправдании.

Условия: negative_experience, observer_invariant, causal_link, agent_can_reason, evidence_available, existing_subject, help, authorized_help, proportionate_help, independent_permission

- Требование учесть основание: A1 + A2 + A3 (успешных подмножеств: 64/512).

- Локальная антиценность: A1 (успешных подмножеств: 256/512).

- Разрешение конкретной помощи: A7 (успешных подмножеств: 256/512).

- Первоначальное основание против действия: A1 + A2 (успешных подмножеств: 128/512).

### C6 — Существующий субъект: принуждение без основания

Недопустимость средства не выводится из запрета другого действия; здесь задано отдельное условие.

Условия: existing_subject, coercive_means, no_independent_permission

- Запрет независимо не оправданного принуждения: A8 (успешных подмножеств: 256/512).

### C7 — Сопоставимый опыт другого вида

Проверка применения одинакового критерия, не конкретной политики.

Условия: comparable_experience, negative_experience, observer_invariant

- Единый критерий оценки: A4 (успешных подмножеств: 256/512).

### C8 — Сопоставимый опыт иного физического субстрата

Абстрактный случай условной чувствительности, не утверждение о сознании какой-либо реальной технологии.

Условия: comparable_experience, negative_experience, observer_invariant

- Единый критерий оценки: A4 (успешных подмножеств: 256/512).

## Универсальность и непротиворечивость

В 8 контекстах проверено 4096 комбинаций принципов и 4096 семантических оценок при полном наборе правил. Для каждого контекста пересечение удовлетворяющих моделей совпадает с замыканием правил. В стандартных контекстах конфликт запрета и разрешения одного действия не обнаружен; это не доказательство глобальной непротиворечивости.

Невыводимость запрета не является доказательством разрешения. Для универсального тезиса нужна полнота покрытия области; эта модель её не устанавливает.

Не покрытые защитным правилом контексты: C4

Если одну и ту же абстрактную операцию без проверки квалифицировать одновременно как чистое создание и независимо оправданную помощь, правила дают несовместимые итоговые статусы. Требуется уточнить область действия, а не считать все правила автоматически согласованными. Отдельное первоначальное основание не является таким конфликтом.

Функциональная независимость в этой модели не доказывает метаэтическую независимость или истинность принципов. Два вспомогательных модуля — оценка неопределённости и допустимость средств — не являются посылками, достаточными для универсального запрета.
