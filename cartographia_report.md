# Cartographia Efilismi v2.1

## Назначение

Новый автономный визуальный слой поверх Atlas Efilismi v2.0. Базовый atlas_unified.json сохранён побайтно. Новые картографические представления находятся в cartographia.json; они не прибавляются к числу установленных семантических отношений.

## Карты

| Раздел | Количество | Метод |
|---|---:|---|
| Общая | 1 | 13 рубрик нормализованных понятий; агрегация имеющихся межрубрикальных отношений, без направления вывода |
| Понятия | 18 | 13 локальных карт онтологии плюс 5 тематических карт Nexus; прямые и реконструированные связи различаются по статусу |
| Аргументы | 18 | Совместные посылки → аргумент → условное заключение; возражения и ответы отдельно |
| Причинность | 1 | 10 редакторских отношений между физическими, феноменальными и оценочными уровнями; указаны исходные абзацы и ограничения |
| Монография | 57 | 1 обзор частей, 7 карт структуры частей, 49 локальных карт глав |

Всего 95 карт, 407 экземпляров рёбер (повторение одного отношения в разных картах допустимо), 932 записи в компактном индексе деталей. Это не число новых философских понятий или доказательств.

## Межглавные связи

Использованы адресные соответствия concept → page из v2.0. Для каждой главы строится множество сопоставленных концептов. Вес пары глав равен числу общих концептов; выбираются до восьми ближайших глав, по убыванию веса, затем по идентификатору. В обзоре частей объединяются концепты всех размеченных глав части. Полученные отношения — тематическое пересечение, не прямые ссылки, не доказательные зависимости. Восемь адресаций без chapter_id исключены из расчёта, но не удалены из базы. Их ID находятся в validation_v2_1.json.

## Как пользоваться

Откройте Cartographia_Efilismi.html в браузере после распаковки архива. Сам файл содержит все данные и работает без сети. Для доступа к предыдущим модулям распакуйте весь архив. Выберите раздел и карту; нажмите на узел или ребро для карточки. Поиск выделяет совпадения и сокращает списки; фильтр типа отношений скрывает другие рёбра. Отложенные отношения по умолчанию скрыты. Масштаб меняется кнопками, большая карта прокручивается. SVG сохраняет текущий фильтр отношений, полный холст.

## Методологические ограничения

- Новые причинные отношения — условная реконструкция, а не независимо проверенная биологическая теория. Первичная Ошибка показана как оценочный диагноз, а не физическая причина.
- Карта охватывает прежде всего 72 понятия нормализованной онтологии и 32 отношения Nexus; не все возможные пары 137 статей энциклопедии.
- Монография от 23.11.2026 сопоставляется по ранее сохранённым страницам; новый полный аудит книги не проводился.
- Отсутствие рёбер не является доказательством отсутствия связи.
- Проверки Chromium выполнены загрузкой HTML-содержимого, поскольку file:// запрещён политикой среды. Межфайловые переходы не проверены.

## Проверка

Уникальность карт, ссылки и конечные узлы, сохранность семантической базы, 26 сценариев интерфейса (13 на каждом из двух разрешений), экспорт SVG. Ошибок JavaScript в проверенных сценариях нет.
